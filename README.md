# 바이브 코딩(Vibe Coding)

## 1. 바이브 코딩이란?

바이브 코딩은 AI를 활용하여 자연어로 코드를 생성하고 수정하는 개발 방식이다.

## 2. 주요 기능

- 자연어 기반 코드 생성
- 코드 자동 수정
- 버그 탐지
- UI 생성 지원
- 코드 리팩토링

## 3. 기술 스택

- ChatGPT
- Claude
- Cursor
- GitHub Copilot
- HTML
- CSS
- JavaScript

## 4. 프로젝트 구조

- index.html
- style.css
- script.js
- images/
- assets/

## 5. 개발 과정

1. 요구사항 작성
2. AI에게 기능 요청
3. 코드 생성
4. 테스트
5. 수정 및 개선
6. 배포

## 6. 장점과 단점

### 장점

- 개발 속도 향상
- 초보자도 개발 가능
- 반복 작업 감소

### 단점

- 코드 이해 부족 가능성
- AI 오류 검증 필요
- 보안 문제 고려 필요
